# 豆瓣电影Top250 爬虫实战（httpx + 正则）
## 项目简介
本项目为**Python爬虫入门练手项目**，基于 `httpx + 正则表达式` 实现静态网页数据采集，完整走通：
**网页请求 → 源码抓取 → 正则解析 → 结构化存储** 全流程。

适合跟随崔庆才《Python网络爬虫开发实战》学习后，巩固基础请求、正则提取、异常处理、本地文件存储能力。

## 技术栈
- 网络请求：`httpx`
- 数据解析：正则表达式 `re`
- 数据存储：`CSV`
- 基础能力：浏览器Headers伪装、异常捕获、结构化数据整理

## 练习目标
搭建标准爬虫采集链路：
`抓取网页数据 → httpx 发起请求 → 正则多字段提取 → 输出结构化数据并本地保存`

强制覆盖核心要点：
- ✅ httpx 发送网络请求
- ✅ 完整 Headers 模拟浏览器伪装
- ✅ 正则表达式提取**3个以上**字段
- ✅ try/except 网络异常捕获处理
- ✅ 数据落地保存为 CSV 结构化文件
- ✅ 代码可直接拓展分页爬取

## 爬取目标与字段
目标站点：豆瓣电影 Top250
```
https://movie.douban.com/top250
```
采集字段：
1. 电影名称
2. 导演信息
3. 上映时间/影片类型
4. 电影评分

## 项目结构
```
douban-spider/
├── douban_top250.py   # 爬虫主代码
├── 豆瓣电影.csv       # 输出结构化数据文件
└── README.md          # 项目说明文档
```

## 运行方式
1. 安装依赖
```bash
pip install httpx
```
2. 直接运行爬虫脚本
```bash
python douban_top250.py
```
3. 运行完毕自动生成 `豆瓣电影.csv`，可用 Excel 直接打开，中文不乱码。

## 核心功能亮点
1. 使用 `httpx.Client` 保持会话请求，写法规范
2. 完整浏览器 Headers 模拟，绕过基础反爬拦截
3. 单行正则一次性匹配多个目标字段，简洁高效
4. 加入网络请求异常捕获，防止程序崩溃
5. 采用 `utf-8-sig` 编码保存 CSV，兼容 Windows Excel
6. 代码结构清晰，易于二次修改和拓展
